Line 1：Identity Line

固定顯示 — 模型 + 計劃 + 專案 + Git + 時間
◉ Opus 4.6 │ Max │ cchub main* ↑2 │ ⏱ 1h 23m

◉ 活動指示燈（紅=有 tool 在跑，綠=閒置）

main* 分支 + dirty（purple + yellow）
↑2 ahead commits（dim）

Line 2：Metrics Line

固定顯示 — Context bar + Usage bar + Burn rate
▰▰▰▰▰▱▱▱▱▱ 45% ctx │ ▰▰▱▱▱▱▱▱▱▱ 25% use │ 1.2k tok/m

▰▱ 新 bar 字元（比 █░ 更精緻）
ctx context 百分比（green→yellow→red）
use 5h usage 百分比（blue→magenta→red）
tok/m token burn rate（每分鐘消耗，dim）

Line 3：Framework Line（條件顯示）

有 AGW/Agent Teams 活動時顯示
├─ ⟳ AGW: review-loop (step 3/5) │ ⬡ Teams: fe✓ be◐ test⏳

├─ 樹狀前綴（dim）
⟳ AGW 圖示（orange）+ combo 名稱 + 進度
⬡ Teams 圖示（green）+ 各 agent 縮寫狀態
無活動時整行隱藏

Line 4：Tools Line（條件顯示）

有 tool 活動時顯示
├─ ◐ Edit: auth.ts │ ✓ Read ×3 │ ✓ Grep ×2 │ ◐ explore [haiku] (2m)

Tools 和 agents 合併到同一行（原本分開兩行）
◐ = 進行中（orange/purple）
✓ = 已完成（green）
agents 追加在 tools 後面，用圖示區分

Line 5：Alert Line（條件顯示）

觸發警告閾值時顯示
└─ ⚠ Context 92% — ~8 calls │ Usage 89% — resets 14:32 (28m)

Line 6：Todos Line（條件顯示）

有 TodoWrite 任務時顯示
└─ ▸ Fix authentication bug (2/5) │ ▪▪▪▪▪

▸ 當前任務名稱
(2/5) 完成進度
▪▪▪▪▪ 微型進度條（green=done, orange=in_progress, dim=pending）

樹狀前綴規則

完整範例 — 所有行都有活動
◉ Opus 4.6 │ Max │ cchub main* ↑2 │ ⏱ 1h 23m
▰▰▰▰▰▰▰▰▰▱ 92% ctx │ ▰▰▰▰▰▰▰▰▰▱ 89% use │ 3.4k tok/m
├─ ⟳ AGW: review-loop (3/5) │ ⬡ Teams: fe✓ be◐ test⏳
├─ ◐ Edit: auth.ts │ ✓ Read ×3 │ ◐ explore [haiku] (2m)
├─ ⚠ Context 92% — ~8 calls │ Usage 89% — resets 14:32
└─ ▸ Fix auth bug (2/5) │ ▪▪▪▪▪

Line 1-2 無前綴（固定顯示）
Line 3+ 用 ├─（中間行）和 └─（最後行）
前綴自動計算：根據實際顯示的行數決定哪個是最後一行
